# Установка DSH Remote на iPhone (без Mac)

Приложение собирается в **неподписанный** `.ipa` на macOS-раннере GitHub Actions.
Apple требует подписи, поэтому последний шаг — подписать IPA **на самом iPhone** и
установить его. Mac для этого не нужен.

## 1. Скачать IPA

1. Откройте **Actions → iOS IPA (unsigned)** в репозитории и запустите сборку
   (`Run workflow`) либо возьмите последнюю успешную.
2. Внизу страницы запуска скачайте артефакт **`ios-ipa-unsigned`** — это ZIP, внутри
   `DSH-Remote-unsigned.ipa` и `.sha256`.
3. Распакуйте ZIP и перенесите `.ipa` на iPhone: AirDrop, «Файлы» (iCloud Drive),
   Telegram «Избранное», почта — любым способом.

Через CLI, если удобнее с компьютера:

```bash
gh run download --repo kharkilirov1/dsh-remote \
  --name ios-ipa-unsigned --dir dist
```

## 2. Что нужно для подписи

| Вариант | Что нужно | Срок действия |
| --- | --- | --- |
| **BuildBox 2.0** (рекомендуется) | сертификат `.p12` + профиль `.mobileprovision` | сколько действует сертификат |
| **AltStore / SideStore** | бесплатный Apple ID | 7 дней, продление автоматически |
| ESign / Feather / Sideloadly | `.p12` + `.mobileprovision` или Apple ID | по сертификату |

> Сертификат разработчика (даже бесплатный, выданный через AltStore/SideStore) можно
> экспортировать в `.p12` + `.mobileprovision` и использовать в BuildBox.

## 3. Вариант A — BuildBox 2.0 (подпись на устройстве)

BuildBox — бесплатное приложение для iPhone, которое **подписывает любой IPA прямо на
телефоне** вашим сертификатом и устанавливает его. Mac не нужен.

1. Установите BuildBox 2.0 на iPhone: скачайте `BuildBox-2.0.0.ipa` из
   [релизов BuildBox](https://github.com/mikevillarroel/buildbox-ios/releases/latest) и
   установите его через AltStore/SideStore/ESign вашим сертификатом (сам BuildBox тоже
   неподписан).
2. В BuildBox откройте вкладку **Sign**, импортируйте:
   - `.p12` (ваш сертификат) и пароль от него,
   - `.mobileprovision` (профиль, где **Bundle ID = `com.dsh.remote`** или wildcard).
3. Загрузите `DSH-Remote-unsigned.ipa` в BuildBox (кнопка импорта / «Поделиться» из
   «Файлов»). При необходимости на вкладке Sign поменяйте display name / bundle id /
   версию — BuildBox умеет править их перед подписью.
4. Нажмите **Sign** — через несколько секунд получите подписанный IPA в **Library**.
5. В Library: свайп влево → **Install**. BuildBox поднимет локальный HTTPS-сервер и
   установит приложение. Подтвердите установку в системном диалоге.

Если профиль не совпадает с bundle id, BuildBox/WDA покажет ошибку подписи — тогда
либо выпустите профиль на `com.dsh.remote`, либо поменяйте bundle id в BuildBox на тот,
что есть в вашем профиле (для free-сертификата это обычная практика).

## 4. Вариант B — AltStore / SideStore (бесплатный Apple ID)

1. Установите **AltStore** (Windows/Mac-компьютер нужен один раз для установки
   AltServer) или **SideStore** (устанавливается полностью с телефона).
2. Войдите бесплатным Apple ID. AltStore подпишет приложение вашим сертификатом.
3. AltStore → **My Apps → +** → выберите `DSH-Remote-unsigned.ipa` (файл должен быть в
   «Файлах» / iCloud Drive).
4. Приложение появится на домашнем экране. Бесплатный сертификат действует **7 дней**,
   AltStore продлевает его при подключении к Wi-Fi (SideStore — через VPN-профиль).

Ограничение бесплатного Apple ID: одновременно не больше 3 приложений и 10 App ID в
неделю — для одного DSH Remote этого достаточно.

## 5. Первый запуск

1. При первом запуске iOS может спросить **«Локальная сеть»** — разрешите: без этого
   приложение не увидит компьютер в LAN (iOS 14+).
2. Разрешите **камеру**, если планируете сканировать QR-код подключения.
3. Введите адрес компьютера (`http://192.168.x.x:3080`) и токен либо отсканируйте
   QR-код из DSH: **Настройки → Подключить мобильное устройство**.
4. Если приложение не подключается — проверьте, что телефон и компьютер в одной сети,
   порт плагина открыт в файрволе Windows, а токен скопирован целиком.

## 6. Частые проблемы

| Симптом | Причина / решение |
| --- | --- |
| «Не удалось установить приложение» | сертификат/профиль не совпадает с bundle id; переподпишите с `com.dsh.remote` или поменяйте id в BuildBox |
| «Не удалось проверить приложение» / «Untrusted Developer» | Настройки → Основные → VPN и управление устройством → доверьтесь сертификату |
| Приложение открывается, но не подключается | не выдано разрешение «Локальная сеть» (Настройки → конфиденциальность), либо HTTP-адрес введён без `http://` |
| «Не удалось загрузить файл» при отправке вложения | файл слишком большой для HTTP-запроса; проверьте `< 20 МБ` |
| Через 7 дней приложение не запускается | истёк бесплатный сертификат — продлите в AltStore/SideStore и переустановите |
| IPA не собирается в Actions | смотрите лог шага «Build iOS»: чаще всего это версия Xcode или несовместимость плагина с Swift Package Manager |

## 7. Альтернатива: сборка на своём Mac

```bash
# macOS + Xcode 16+
flutter pub get
bash tools/build_ios.sh          # dist/DSH-Remote-unsigned.ipa
# подписать: Xcode (автоматическая подпись) или ios-deploy/ios-sign
```

Подробности по CI и подписи — [`docs/IOS-BUILD.md`](IOS-BUILD.md).
